## 📖 关于诗云

**诗云** 是一款专注于中华古典文学阅读的 Android 原生应用。

我们致力于为喜爱古典文学的读者提供一个安静、温润、优雅的阅读空间。在这里，千百年来的经典诗词与文赋褪去了繁复浮躁的商业干扰，化为指尖触手可及的篇章。无论是晨昏间隙偶遇的名篇佳句，还是静夜独处时的沉浸研读，诗云都愿陪伴你品味古典文字的意境与力量。

---

## 📚 丰沛的典藏内容

- **万余首传世名作**：收录先秦至近现代的 12,000 余首诗词文赋，涵盖古体诗、近体诗（绝句、律诗）、词调词牌、散曲杂剧、辞赋及经典散文等多种文体。
- **两千余位文人小传**：汇聚 2,400 余位历代文人的生平小传与背景介绍，助你了解名篇背后的作者襟怀与时代风貌。
- **三百余部经典选本文集**：完整收录 380 余部传世选本与经典文集（如《唐诗三百首》《宋词三百首》《古文观止》《诗经》《楚辞》《古诗十九首》等），完整保留原书编目序列。

## 🌸 核心阅读体验

### 1. 沉浸首页推荐
- **名句卡片轻触展开**：首页以典雅的半透明宣纸卡片呈现每日精选名句，轻触卡片即可展开完整正文与详细信息。
- **流畅滑动手势**：卡片支持上下滑动或左右滑动快速切换上一首与下一首作品，随心偶遇古典诗意。

### 2. 深入品读与研读辅助
- **纯净阅读正文**：作品详情页去除一切与阅读无关的冗余视觉元素，字里行间张弛有度。
- **详实研读面板**：针对包含注解的作品提供辅助研读面板，难懂字词注释、白话全文翻译与名家赏析一触即达。
- **快捷双击收藏**：在正文区域双击屏幕或点击右上角收藏图标，即可将喜爱的篇目加入个人“藏卷”，便于随时翻看回顾。

### 3. 多维探索与便捷查找
- **朝代编年浏览**：按中华历史年代先后顺序排列历代名作，感知诗文风貌的历史演进。
- **体裁细分查阅**：支持按诗、词、曲、文一级分类检索，并可进一步细化至五言绝句、七言律诗、词调曲牌、骈文散文等体裁维度。
- **选本文集导读**：提供 380 余部经典选本文集的目录网格卡片，进入文集可按全书原篇目顺序连续翻阅品读。
- **全文关键词搜索**：支持输入诗词标题、作者姓名或正文名句关键词进行快速检索，并在搜索结果列表中展示匹配段落的摘要预览。

## 🎨 东方美学主题

应用内置 10 套精心调配的中国传统色与自然水墨主题，满足不同心境与环境下的阅读需求：

- **六套经典纸质雅集**：
  - **宣纸古籍**（默认）：温润米黄纸质，还原古籍书卷气息。
  - **竹青雅韵**：淡雅苍青竹色，清心宁神。
  - **黛青山水**：远山如黛，沉静端庄。
  - **朱砂雅集**：朱砂与泥金相映，古朴典雅。
  - **琥珀秋笺**：暖意秋色，温和护眼。
  - **墨夜清辉**：暗底墨韵，夜间阅读温和不刺眼。
  - *底栏图标自动与当前主题色相融合，页面浑然一体。*
- **四套四时水墨插画**：
  - **柳烟春晓**（春）、**荷风清韵**（夏）、**枫笺染霜**（秋）、**寒江雪隐**（冬），融入古典时序画卷与舒适视觉遮罩。

## 📐 精细阅读排版设置

阅读界面提供便捷的排版调节弹窗，支持对字形与间距进行微调：

- **字体选择与本地导入**：
  - **支持导入本地字体**：可自主导入手机本地的 `.ttf` 或 `.otf` 格式中文字体文件，并支持字体管理与一键选用。
- **基础排版参数**：
  - 正文字号微调（14 ~ 34 sp）；
  - 行高倍率微调（1.30x ~ 2.40x）。
- **高级排版参数**：
  - 文字字距、屏幕左右边距精细微调；
  - 诗句垂直间距、分联留白、词阕与段落留白调节；
  - 古文自然段首行缩进独立开关。
- **一键恢复默认**：随时可一键重置所有版式参数至初始默认状态。

## 📥 下载与安装

- **系统要求**：支持 Android 10.0（API 29）及以上版本的手机与平板设备。
- **获取方式**：
  - 前往 GitHub 项目主页的 [Releases 页面](https://github.com/Taevor/shiyun/releases)；
  - 在最新发布版本的 **Assets** 列表中下载 `app-release.apk`；
  - 下载完成后在系统文件管理或通知栏中点击安装包直接安装即可开始阅读。
